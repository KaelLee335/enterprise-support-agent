# 本机演示录制脚本

目标成片：约 60–90 秒，展示项目可运行、售后问答、模拟订单只读查询和评估报告。录制前启动 Docker 中的 Dify，再运行 `scripts/run_ui.ps1` 并打开 `http://localhost:8502`。

## 录制顺序

1. 展示“售后对话”页和页面顶部的演示数据说明。
2. 输入“退货期限是多久？”展示知识库回答与引用（若本次 API 返回引用）。
3. 输入“查询演示订单 DEMO2026110006 的状态”展示模拟订单查询；说明订单状态是固定演示数据。
4. 展示 API 未提供结构化工具调用明细时，界面明确标注无法确认工具执行状态。
5. 打开“评估报告”页，展示案例数、当前有数据的指标和“未测量”指标；不要把未测量解释为通过。

## 保存与隐私检查

- 可运行本机 OBS 启动脚本打开 OBS Studio，然后开始录制。
- 开始前检查场景来源：仅保留演示浏览器窗口采集，停用显示器采集，避免录入其他桌面内容。
- OBS 默认录制目录可能是 Windows“视频”文件夹；录制后把文件复制到项目的 `docs/demo.mp4`。
- 输出保存为 `docs/demo.mp4`，产品截图保存到 `docs/screenshots/`。
- 上传或提交前检查画面，确保没有 API Key、Dify 管理凭据、个人账号或桌面通知。
- 本机 Dify 地址只在本机有效；视频中应称为“本机演示”，不要称为公网服务。

当前机器已确认安装 OBS Studio 33.0.0，桌面脚本用于启动 OBS，但不会自动开始录制。仓库目前尚未生成视频文件；该脚本依赖本机安装路径，不包含在仓库中。
